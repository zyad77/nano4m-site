What we built

What We Implemented

Masking
Span masking for text
Contiguous segments on scene_desc with geometric distribution (p=0.2) and sentinel tokens.
Masking
Block masking for images
Rectangular blocks on tok_rgb@256, tok_depth@256, tok_normal@256.
Masking
Mixed masking strategy
Combines random and structured masking with configurable probability (50/50 in V4).
Training
5 controlled experiments
Baseline, V1, V2, V3, V4 trained under identical setup on EPFL SCITAS (2×L40, 5,000M tokens).
Evaluation
Image-to-text pipeline
BLEU-4, CIDEr, ROUGE-L, Exact Match scored over 200 validation samples.
Evaluation
Text-to-image pipeline
Custom CLEVR fidelity verifier (Grounding DINO) + CLIP alignment score.
Scripts
Generation & scoring scripts
Prediction generation, metric scoring, sample comparison, and visual HTML reports.
Testing
Unit tests
tests/test_structured_masking.py — verifies encoder/decoder disjointness for all strategies.
Team organization

Task Distribution

Ali Tahri Hassani & Zyad Tajeddine

Implementation of masking strategies (SimpleMultimodalMasking: span, block, structured, and mixed primitives). Controlled training experiments, configuration, distributed training on SCITAS, logging, and checkpointing via WandB.

Nour Alaoui Ismaili & Ayman Belbachir

Evaluation methods: image-to-text and text-to-image generation pipelines, metric scorers, CLEVR fidelity verifier with Grounding DINO and CLIP, and unit tests that validate the masking strategies.

All Members

End-to-end pipeline design and integration, experimental analysis, slides, and final report writing. The checkpoint logistics challenge (multi-GB .pth files across the cluster) was handled jointly.

Codebase Structure

path com-304-FM-project-2026-main/nano4M/nanofm/data/multimodal/masking.py
Core masking logic. Contains SimpleMultimodalMasking (baseline) and StructuredMultimodalMasking subclass with span, block, and mixed primitives.
path com-304-FM-project-2026-main/nano4M/tests/test_structured_masking.py
Run with python -m unittest discover -s tests. Asserts encoder/decoder position disjointness across all 5 masking variants.
path com-304-FM-project-2026-main/nano4M/generate_scene_desc_predictions.py
Loads a trained .pth checkpoint, runs greedy ROAR decoding on 200 validation samples, and saves reference/prediction pairs as JSON.
path com-304-FM-project-2026-main/nano4M/score_scene_desc_predictions.py
Reads the JSON pairs from the generator script and computes BLEU-4, lightweight TF-IDF CIDEr, ROUGE-L, and Exact Match on 0–100 scale.
path com-304-FM-project-2026-main/nano4M/compare_one_sample_all_models.py
Runs Baseline, V1, V2, V3, V4 on the same validation sample and exports a side-by-side comparison report for qualitative analysis.
